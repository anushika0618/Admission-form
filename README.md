# University Admission Website — HTML Practice Project

A simple multi-page university website built with HTML. The pages present introductory university information, course listings, and an admission form.

## Pages

- `index.html` — homepage with introductory content and navigation.
- `about.html` — university overview, mission, infrastructure, and facilities.
- `courses.html` — sample undergraduate and postgraduate course information.
- `admission.html` — an HTML form covering personal, contact, academic, course, guardian, and document-upload fields.

## Built with

- HTML

## Run locally

No build tools are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Use the page navigation to open the other HTML pages.

## Scope and limitations

This is a front-end practice project. The admission form currently demonstrates HTML form controls and browser-native validation; the repository documentation does not establish a backend, database, or application-submission service. Do not enter real personal information into the demo form.

The university details and course information are sample page content and should not be treated as verified official information.

## Possible improvements

- Add responsive styling with CSS.
- Associate every form control with a unique `id` and matching label.
- Add appropriate `name` attributes and stronger field validation.
- Add a backend only if a real application-submission workflow is intended.
